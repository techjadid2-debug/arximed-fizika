# Physica UI/UX, 3 til va “Ilk qadam” roadmap rejasi

## Kelishilgan MVP chegarasi

- Kirish tizimi va database keyingi bosqichga qoldiriladi.
- Interaktiv tajriba mazmuniga qarab 2D Canvas yoki 3D WebGL ishlatiladi.
- Apple uslubidagi yumaloq shakllar, dark/light rejim hamda Apple Blue aksent ranglari qo‘llanadi.
- Til prefikslari: `/uz`, `/en`, `/ru`; boshlang‘ich til — o‘zbekcha.
